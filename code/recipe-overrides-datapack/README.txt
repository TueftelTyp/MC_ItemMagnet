ItemMagnet v1.2 recipe overrides for Minecraft Java 26.3.
Copy this entire directory to world/datapacks/ and run /reload.
Edit data/itemmagnet/recipe/{weak_magnet,mid_magnet,strong_magnet}.json to change ingredients, layout and result count.
These files override the built-in mod recipes because they use identical recipe IDs.
Delete the override pack to restore built-in recipes.
